# Сравнение OCR и предобработки (день 2)

Движок: **Tesseract 5 (rus)**. Документы: 10 из 30 открытых (по 3–4 каждого типа), условия снимка получены искусственной порчей чистых PNG (`src/dekanat/bench/degrade.py`). Метрики считает `evaluate.py` организаторов. **EasyOCR: сравнение выполняется в Colab (`notebooks/ocr_benchmark.ipynb`), результаты будут добавлены.**

| Условие | Поля: без предобр. | Поля: с предобр. | Проверка: без → с | Вопросы: без → с | OCR, с/док (с предобр.) |
|---|---|---|---|---|---|
| Чистый документ | 1.000 | **1.000** | 1.00 → 1.00 | 1.00 → 1.00 | 2.11 |
| Наклон 5° | 0.868 | **1.000** | 0.40 → 1.00 | 0.93 → 1.00 | 1.9 |
| Наклон 15° | 0.292 | **1.000** | 0.00 → 1.00 | 0.70 → 1.00 | 1.94 |
| Наклон 30° | 0.198 | **1.000** | 0.00 → 1.00 | 0.70 → 1.00 | 1.76 |
| Размытие | 0.613 | **0.868** | 0.30 → 0.60 | 0.72 → 0.88 | 2.25 |
| Низкое разрешение (560 px) | 0.713 | **1.000** | 0.10 → 1.00 | 0.80 → 1.00 | 2.03 |
| Тень | 0.198 | **1.000** | 0.00 → 1.00 | 0.70 → 1.00 | 2.18 |
| Блик | 1.000 | **1.000** | 1.00 → 1.00 | 1.00 → 1.00 | 2.0 |
| JPEG-шум | 0.970 | **0.988** | 0.70 → 1.00 | 0.93 → 1.00 | 2.09 |
| «Фото с телефона» (наклон+тень+размытие+шум) | 0.128 | **0.945** | 0.00 → 0.60 | 0.62 → 0.88 | 2.52 |

## Выводы

- На чистых документах предобработка ничего не портит (1.000), поэтому её можно держать включённой по умолчанию.
- Наклон, низкое разрешение и тень без предобработки ломают распознавание почти полностью (поля 0.13–0.71); с ней они дают 1.000.
- Остаются слабые места: **размытие** (0.87) и «фото с телефона» (0.95): ошибки в основном в цифрах дат. Кандидаты на улучшение: запасной движок (EasyOCR) для снимков с низкой уверенностью OCR.
- Что исправлено по ходу: шумоподавление NLM занимало ~10 с на страницу (заменено билатеральным фильтром, ~0.1 с); добавлены выравнивание освещения (тени) и усиление резкости только для размытых снимков.
- Предобработка описана в `configs/settings.yaml` (`preprocess`), каждый шаг включается флагом.

Ограничения: 10 документов вместо 30, порчи искусственные, один движок. Воспроизвести: `python scripts/benchmark_ocr.py --docs-dir data/open --engines tesseract`.
